# Contributing

Thank you for looking.

## Issues: yes, please

Bug reports, install problems, documentation gaps and feature requests are welcome as [GitHub issues](https://github.com/quoxai/quoxcore/issues). A good report has the version (`VERSION`), your OS and Docker version, what you did, what you expected and what happened.

Security problems go to security@quox.ai, not an issue. See [SECURITY.md](SECURITY.md).

## Pull requests to core: no

This repository is a release mirror of a private development repository, and the core is licensed under the [Quox Community Source Licence 1.0](LICENSE), which does not permit modified versions of the core to be distributed. We cannot merge pull requests here. If you have found a fix, describe it in an issue; a code snippet in the issue is welcome.

## Build on it instead

Plugins, agents, connectors, workflows and skills built through the documented interfaces belong to you, and you can publish or sell them. Start with the plugin SDK (public release coming soon) and [QuoxMCP](https://github.com/quoxai/quoxmcp).
